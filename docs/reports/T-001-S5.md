## 4. 未預期發現

1. **build 曾產生語法錯誤的 index.html**（第一次煙霧測試失敗）：原因是 `String.prototype.replace` 用字串當替換值時，原始碼中的 `$'` 被當成特殊樣式。已改為函式替換並加入 `T-BUILD-01` 的注入標記／GAME_DATA 一致性檢查；此類錯誤現在會在 `npm test` 的 engine 階段就被抓到。
2. 分派單 S5 要求 `playwright.config.js` 與 `@playwright/test`，實作採對話指令的純 Node 腳本；兩者測試內容等價（T-UI-01～04 ＋ 兩視圖）。若 release-manager 要求嚴格對齊分派單，可另補 config（約 20 行）。
3. 規格 §9.2 建議 `test` ＝ engine ＋ ui；本案在中間插入 `build`（對話指令要求），確保 `test:ui` 永遠測最新產物。
4. 煙霧測試的走法為「翻兩顆就停、不買」，未覆蓋購買與爆倉路徑；購買路徑已在手動擷取腳本走過（買保險成功），爆倉路徑只由 engine 測試覆蓋。建議 G5 qa-tester 加固定 seed 的爆倉／購買腳本。
5. `docs/qa/shots/` 為測試產物，每次 `npm test` 會覆寫；是否納入版本控制由 release-manager 決定。
